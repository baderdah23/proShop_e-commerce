Pro-Store API · توثيق الـ API

هذه الصفحة هي الدليل الكامل لجميع نقاط الاتصال (Endpoints) في واجهة المتجر الخلفية. كل نقطة موثّقة بالعربية والإنجليزية مع أمثلة حقيقية على المدخلات والمخرجات.

This page is the complete guide to every endpoint of the store backend. Each endpoint is documented in Arabic and English with real input & output examples.

🌍 عنوان الخادم / Base URL

كل المسارات تبدأ من جذر الخادم — بدون بادئة مثل /api/v1:

كل المسارات تبدأ من جذر الخادم مباشرة بدون أي بادئة.

http://localhost:8000          ← محلياً (لوحة التطوير)
https://YOUR-BACKEND-DOMAIN    ← على الاستضافة (Vercel مثلاً)

🔐 المصادقة / Authentication

التوثيق يتم عبر كوكي (Cookie) اسمها token تصدرها خوادم /auth/login و /auth/signup. هي httpOnly أي لا تُرى من جافاسكربت. عند إرسال أي طلب يحتاج تسجيل دخول، أرسل الكوكي مع الطلب تلقائياً (credentials: 'include' في المتصفح، أو -b cookies.txt في curl).

Authentication uses a cookie named token, issued by /auth/login and /auth/signup. It is httpOnly (JavaScript cannot read it). Send it automatically with protected requests.

💡 مثال سريع على تسجيل الدخول ثم طلب السلة / Quick example: login then fetch cart
# 1) تسجيل الدخول وحفظ الكوكي
curl -X POST http://localhost:8000/auth/login \
  -H "Content-Type: application/json" \
  -d '{"email":"test@example.com","password":"Passw0rd!"}' \
  -c cookies.txt

# 2) استخدام الكوكي في الطلبات المحمية
curl http://localhost:8000/cart -b cookies.txt

📄 الترقيم / Pagination

بعض القوائم تدعم ?page= (افتراضي 1) و ?limit=. المنتجات ترجع أيضاً "total" (عدد الكلي) و "page".

ملاحظة: عند رجوع قائمة فارغة من بعض واجهات التصنيفات/المنتجات قد يرجع 404 بدلاً من مصفوفة فارغة — هذا سلوك معروف في الواجهات المبنية بـ factory.

GET /products?page=2&limit=10&sort=price_asc

🔐 Auth · الحسابات والمصادقة

التسجيل، الدخول، الملف الشخصي، واستعادة كلمة المرور. التوكن يُرسل كوكي اسمه token لمدة 30 يوم.
Sign up, login, profile and password recovery. The JWT is set as a token cookie valid for 30 days.
POST/auth/signup🔓 عام / Public
إنشاء حساب جديد. عند النجاح تُصدر كوكي التوكن تلقائياً.
Create a new account. On success the token cookie is set automatically.

الحقل Fieldالنوع Typeمطلوب Req.القاعدة Rule

phonestring✔9–20 رقم، يقبل + في البداية
passwordstring✔6+ أحرف، وتشمل حرف كبير + صغير + رقم + رمز خاص

📌 ملاحظات مهمة / Important Notes

  • الكوكي token هو وسيلة التوثيق الوحيدة — لا يوجد دعم لـ Authorization Header.
  • There is no Authorization: Bearer support — cookie only.
  • الكوبونات تُطبَّق بأحرف كبيرة: pro2026 و PRO2026 متكافئان.
  • الدفع بالبطاقة يحتاج خطوتين: POST /payments/process ثم إتمام الدفع بـ Stripe.js باستخدام clientSecret ثم POST /payments/:orderId/confirm.
  • قائمة فارغة من بعض واجهات factory قد ترجع 404 بدلاً من مصفوفة فارغة.
  • في الطلبات والمفضلة والسلة: معرف المنتج هو UUID وليس رقماً — وانتبه لاختلاف الاسم: productId (Cart/Wishlist) مقابل product_id (Reviews).
